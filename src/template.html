Adattatore di configurazione per PA-500

Prende l'export XML di un firewall Palo Alto e lo prepara per i PA-500 con PAN-OS 12.1: converte il routing all'Advanced Routing, sposta le interfacce sulle porte del nuovo modello, sistema l'HA e ti dice cosa resta da fare a mano.

Lavora solo in questo browser: la config non viene caricata da nessuna parte e la pagina funziona anche senza rete.

1

Carica le configurazioni

Esporta la config da Device > Setup > Operations > Export named configuration snapshot, oppure usa il device state: il file viene letto qui, in locale.

Config sorgente

Il running-config.xml del firewall attuale o il suo device state (.tgz).

oppure trascinalo qui

Config del PA-500 (facoltativa)

L'export del nuovo firewall: serve a mantenere management, HA e amministratori già configurati.

oppure trascinalo qui
2

Scegli il modello e assegna le porte

Ogni interfaccia della sorgente va su una porta del PA-500 o viene esclusa. Le sub-interfacce seguono la porta madre.

assegnata HA da correggere libera PoE

Seleziona un'interfaccia nella tabella, poi clicca una porta del pannello per assegnarla. La numerazione ethernet1/N segue la posizione sul pannello frontale: verificala con show interface all sul PA-500.

Carica la config sorgente per vedere le sue interfacce.

3

Scegli le regole

Le regole standard coprono i limiti noti dei PA-500. Il risultato si aggiorna a ogni modifica.

    Regole personalizzate

    Interventi XPath applicati dopo le regole standard, nell'ordine dell'elenco. Restano salvati in questo browser; esportali per usarli su un altro PC.

    4

    Correggi gli errori di validate o commit

    Carica la config sul PA-500, lancia validate e incolla qui gli errori. Per ognuno trovo l'elemento nella config convertita e propongo una correzione, che diventa una regola personalizzata: così vale anche per le prossime config.

    Risultato

    Carica la config sorgente: qui compaiono il report della conversione e il file da scaricare.
